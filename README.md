# 또타지하철 — TTA Personalized Mobility

> 단순한 길찾기를 넘어, 나에게 맞는 이동 경험을.

서울교통공사 '또타지하철'을 고도화한 **개인 맞춤형 지하철 이동 모바일 앱 프로토타입**입니다.
React + TypeScript + Vite + Tailwind CSS로 만들었고, 스마트폰과 데스크톱(시연 모드) 모두에서 직접 조작할 수 있습니다.

> ⚠️ 노선도는 **개략 노선도**이며 실제 지도가 아닙니다. 역사 내부 이동거리·엘리베이터·열차 시간 등은 모두 **시연용 예시 데이터**입니다.

---

## 1. 핵심 기능

| 기능 | 위치 | 내용 |
|---|---|---|
| ① Personalized Routing | 경로 탭 | 출발·도착역 검색/교체, 4가지 조건(빠른 이동·환승 최소화·도보 최소화·엘리베이터 우선) 복수 선택 + 우선순위, 경로별 추천 이유 |
| ② Station Intelligence | 경로 상세 · 홈 지도에서 역 탭 | 추천 하차 위치, 엘리베이터/계단, 환승통로 거리, 승강장 방면 |
| ③ Personal Mobility Pace | 이동 › 스마트 환승, MY | 보행속도(느림·보통·빠름·측정값)에 따라 환승시간·환승 가능 여부 실시간 변화, 다음 열차 추천 |
| ④ Smart Alighting Alert | 이동 › 스마트 하차 | 세로형 노선 UI, 현재/다음 역, 남은 역 수, 도착 예정시간, 1~2정거장 전 알림 + 도착 알림(진동·알림음) |
| ⑤ Dynamic Rerouting | 이동 › 장애 대응 | 엘리베이터 고장·열차 지연·운행 중단·환승통로 폐쇄 이벤트, 기존 조건을 유지한 대체 경로 선택 |

경로 탐색은 실제 그래프 알고리즘(다익스트라)으로 계산되므로, 어떤 역 조합이든 조건·보행속도·장애 상황에 따라 결과가 실제로 바뀝니다.

## 2. 발표 시연 시나리오 (광화문 → 잠실)

1. **홈** › 상단 검색창의 도착역을 눌러 `잠실` 검색 (출발은 광화문으로 기본 설정)
2. 경로 탭에서 **이동 조건**이 `1. 엘리베이터 우선 · 2. 도보 최소화`인지 확인 (‘조건 변경’으로 수정 가능)
3. 보행속도 **보통** 선택
4. 결과: **천호 환승(5→8호선) 경로가 ‘추천’** — 지도에 굵은 선으로 표시, 다른 경로는 옅게 표시
5. 다른 경로를 눌러 지도와 정보가 함께 바뀌는 것 확인 → 다시 추천 경로 선택 → **이 경로로 안내 시작**
6. **스마트 환승**: 천호역 열차 출발까지 `04:00`, 예상 환승 `03:17`, 여유 `00:43`
7. 보행속도를 **느림**으로 바꾸면 여유가 마이너스가 되며 “다음 열차를 추천해요”로 변경 → 다시 보통 → **환승 이동 시작** (5× 배속 가능)
8. **스마트 하차** › **하차 알림 시작** → **다음 역** 버튼으로 이동
9. **장애 대응** › **엘리베이터 고장** 발생
10. 기존 조건(엘리베이터 우선·도보 최소화)을 유지한 **대체 경로(왕십리 환승 등)** 선택 → **이 대체 경로로 변경**
11. 스마트 하차에서 계속 진행 → 1정거장 전 **하차 사전 알림** → **도착 알림** → 안내 종료

> 팁: 스마트 하차의 ▶ 버튼을 누르면 3.5초마다 자동으로 다음 역으로 진행합니다.

## 3. 설치 및 실행

Node.js **20.19 이상**(권장 22 LTS)이 필요합니다.

```bash
npm install      # 패키지 설치
npm run dev      # 개발 서버 실행 → http://localhost:5173
npm run build    # 배포용 빌드 (dist 폴더 생성)
npm run preview  # 빌드 결과 미리보기
```

스마트폰으로 개발 서버를 보려면 PC와 같은 Wi-Fi에서 `npm run dev` 실행 후 터미널에 표시되는 `Network:` 주소(예: `http://192.168.0.10:5173`)로 접속하세요.

## 4. GitHub 업로드

1. GitHub에서 새 저장소(Repository) 생성 (예: `tta-subway`, README 추가 체크 해제)
2. 프로젝트 폴더에서:

```bash
git init
git add .
git commit -m "또타지하철 프로토타입"
git branch -M main
git remote add origin https://github.com/<내-아이디>/tta-subway.git
git push -u origin main
```

`node_modules`와 `dist`는 `.gitignore`에 포함되어 있어 업로드되지 않습니다.

## 5. Vercel 배포

1. https://vercel.com 에 GitHub 계정으로 로그인
2. **Add New… › Project** → 방금 올린 `tta-subway` 저장소 **Import**
3. 설정은 자동 인식됩니다 (Framework: **Vite**, Build: `npm run build`, Output: `dist`)
4. **Deploy** 클릭 → 약 1분 후 `https://tta-subway-xxxx.vercel.app` 주소 발급 (HTTPS 자동 적용)
5. 이후 GitHub에 push할 때마다 자동으로 재배포됩니다.

`vercel.json`에 SPA 리라이트가 설정되어 있어 `/route`, `/move`, `/my` 주소에서 **새로고침해도 404가 나지 않습니다.**

### 스마트폰에서 앱처럼 쓰기
배포 주소를 스마트폰 브라우저로 연 뒤 **홈 화면에 추가**하면 주소창 없이 전체 화면 앱처럼 실행됩니다.
(iOS Safari: 공유 › 홈 화면에 추가 / Android Chrome: ⋮ › 홈 화면에 추가)

## 6. 프로젝트 구조

```
tta-subway/
├─ index.html
├─ package.json
├─ vite.config.ts · tsconfig*.json · vercel.json · .gitignore
├─ public/                 # 파비콘, 웹앱 매니페스트
└─ src/
   ├─ main.tsx · App.tsx   # 앱 진입점, 이동 중 알림 엔진
   ├─ index.css            # Tailwind + 브랜드 컬러 토큰
   ├─ data/network.ts      # 개략 노선도·환승 시설 예시 데이터
   ├─ lib/routing.ts       # 맞춤 경로 탐색·평가·환승시간 계산·장애 반영
   ├─ state/store.tsx      # 전역 상태 (React Context, 설정은 localStorage 저장)
   ├─ components/          # 지도(SVG), 하단 시트, 탭바, 역 검색, 환승 동선 등
   └─ screens/             # 홈 · 경로 · 이동 · MY
```

## 7. 디자인 기준

- 서울교통공사 CI 기반 컬러: Primary `#293896`, Secondary `#5675D8`, Light `#EAF0FC`
- 브랜드 블루는 주요 버튼·선택 상태·경로 강조에만 사용, 노선색은 노선 표시에만 사용
- 공식 로고 파일이 없으므로 로고는 만들지 않고 서비스명 텍스트만 표기
- 데스크톱(가로 600px 이상)에서는 스마트폰 프레임 시연 모드로 표시
- 글꼴: Pretendard (CDN, 연결 불가 시 시스템 글꼴로 대체)

## 8. 참고

- 실제 센서·실시간 API는 연결되어 있지 않습니다. 보행 측정은 ‘시뮬레이션’ 또는 ‘직접 걸어서 측정(10m 구간 타이머)’ 방식입니다.
- 알림은 앱 내 배너 + 진동(지원 기기) + 알림음으로 동작합니다. iPhone Safari는 웹 진동을 지원하지 않습니다.
